# Alienated

A terminal ASCII game. The end of the world is impending because of space war, you lied about your CV and ended up on the ship going to Mars.
You go on an adventure getting to know your teammates, the inner workings of a spaceship as well as how to do the job which you lied about being an expert on.

**The better your relationship with your crewmates, the easier their minigames get.**

## Run it in Windows terminal


pip install -r requirements.txt
python main.py


Needs Python 3.9+ and a terminal at least 80x24. 

## Controls

| Arrows / WASD | Move, pick dialogue choice |
| E / Enter / Space | Interact, continue, confirm |
| 1-9 | Pick a dialogue choice directly |
| ESC | Quit |

**Recommended order of in-game interactions for the best experience:**
1) V
2) R
3) E
4) V or R
5) N
6) C
7) V or R
